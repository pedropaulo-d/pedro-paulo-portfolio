Dados & Engenharia

Pipeline de Dados da B3

Pipeline de engenharia de dados ponta a ponta para o mercado financeiro brasileiro (B3): ingestão com Python/yfinance, camada raw em Parquet no MinIO (S3), warehouse em DuckDB, modelagem dimensional (Star Schema) com dbt e orquestração no Airflow. Calcula indicadores como médias móveis, volatilidade e dividend yield, com execução idempotente e CI de segurança (pip-audit, gitleaks).

  • Python
  • Airflow
  • dbt
  • DuckDB
  • MinIO
  • Docker
GitHub

Data Warehouse de Marketing (ELT)

Pipeline ELT que consolida Meta Ads e Google Ads em um data warehouse PostgreSQL: extração incremental pelas APIs nativas, orquestração no Airflow e transformações com dbt nas camadas Bronze, Silver e Gold. A bronze guarda o payload bruto em JSONB append-only, o que permite reprocessar tudo sem chamar a API de novo; a gold entrega um Snowflake Schema com 6 dimensões encadeadas, SCD Tipo 2 para versionar o histórico das campanhas e 72 testes de qualidade no dbt. Tudo containerizado com Docker.

  • Python
  • Airflow
  • dbt
  • PostgreSQL
  • Docker
  • ELT
GitHub

Desafio Lighthouse · Dados e IA

Desafio técnico ponta a ponta para a LH Nautical, do CSV bruto ao dashboard executivo: gerador de schema escrito só com a biblioteca padrão do Python, carga no PostgreSQL via COPY em transação única, análises em SQL com dimensão de calendário, previsão de demanda validada em walk-forward (sem data leakage) e recomendação de produtos por similaridade de cosseno. Cada etapa coberta por testes unitários e de integração.

  • Python
  • SQL
  • PostgreSQL
  • Forecasting
  • Recomendação
  • Testes
GitHub

Análise de Dados de Torneios da FIFA

Análise exploratória de resultados históricos de torneios da FIFA com Python, Pandas e Plotly. Limpeza e tratamento de três bases — resultados de partidas, artilheiros e disputas de pênalti — e visualizações sobre o fator casa, a distribuição de gols por minuto de jogo, as seleções mais vitoriosas em Copas e o impacto de cobrar primeiro nas decisões por pênalti.
